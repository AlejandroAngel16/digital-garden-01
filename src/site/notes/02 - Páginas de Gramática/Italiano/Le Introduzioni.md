# Le Introduzioni

## Saludos Introductorios

Cuando nos introducimos ante una persona nueva, lo primero que tenemos en cuenta es el tiempo del día. ¿Es de mañana, tarde, noche? Es importante conocer que la forma en como se interpreta el tiempo dentro del lenguaje italiano es muy seguramente distinta si tú no vives en el país objetivo.

| Italiano        | Español       |
| --------------- | ------------- |
| Buongiorno      | Buenos días   |
| Buon pomeriggio | Buenas tardes |
| Buonasera       | Buenas tardes |
| Buonanotte      | Buenas noches |



> [!info]
> - **Buongiorno** es un saludo matinal que va desde las 6 a.m. hasta las 12 p.m.
> - **Buon pomeriggio** es usado entre las 12 p.m. hasta las 5 o 6 p.m.
> - **Buonasera** es usado entre las 5-6 p.m. hasta la medianoche.
> - **Buonanotte** es un saludo específico para despedirse en la noche antes de dormir o para la madrugada antes de que salga el sol.

Podemos decir entonces que el uso de estas [[La Perífrasis Verbal y Locución Verbal\|locuciones verbales]] tienen seguramente un uso cultural distinto, por eso es bastante importante conocer el contexto en el cual se usan estas palabras.
## Saludos Breves
Si deseamos ser más directos o familiares con nuestros saludos, hay muchas formas dependiendo del nivel de familiaridad que tengamos con la otra persona.

| Italiano     | Español                 |
| ------------ | ----------------------- |
| **Ciao**     | Hola/adiós              |
| Come stai?   | ¿Cómo estás? ¿Cómo vas? |
| Come sta?    | ¿Cómo está?             |
| Benvenuto(a) | Bienvenido(a)           |
| Piacere      | Encantado(a)            |
| -/-          | -/-                     |
| Come va?     | ¿Cómo le va? ¿Cómo va?  |
| Come vai?    | ¿Cómo te va? ¿Cómo vas? |

> [!info] 
> - **Va bene** funciona como una pregunta y una respuesta, es de carácter positivo. De manera alternativa podemos utilizar la frase: “Tutto bene?” que se interpreta de manera muy similar.
> - **Vabbè** Es una contracción de **va bene** y se usa de manera casual.

## Despedidas
Hay bastantes formas de despedirse (salutarsi) también, unas más usadas que otras y unas más formales que otras.

| Italiano       | Español         |
| -------------- | --------------- |
| A dopo         | Hasta luego     |
| A presto       | Hasta pronto    |
| Ci vediamo     | Nos vemos       |
| Addio          | Adios           |
| Arrivederci    | Hasta luego     |
| Buona giornata | Ten un buen día |


> [!info] 
> - **Arrivederci** es usado considerablemente ya que cumple con ser formal pero no demasiado.
> - **Ciao** tiene doble utilidad, tanto para saludar familiarmente como para una despedida corta.

## Afirmaciones y Negaciones
No nos podemos olvidar de palabras tan importantes para hacernos expresar como ‘sí’ y ‘no’.

| Italiano     | Español      |
| ------------ | ------------ |
| Sì           | Sí           |
| No           | No           |
| Certo che sì | Claro que sí |
| Certo che no | Claro que no |
| Giusto/Ovvio | Obvio        |

> [!info] 
> **Giuto** es una forma muy común de expresión y es utilizada de manera positiva.

## Disculpas y Expresiones Menores

| Italiano    | Español                                |
| ----------- | -------------------------------------- |
| Mi dispiace | Lo siento                              |
| Mi scusi    | Discúlpeme                             |
|             | -/-                                    |
| Così così   | Ni fu ni fa/Así o asá/Pues sí, pero no |
| Più o meno  | Más o menos                            |

> [!info] 
> **Così così** es una expresión común y se asocia comúnmente a la expresión ‘más o menos’ del español. Sin embargo, esta interpretación no es necesariamente correcta. El uso de esta expresión va más desde la indiferencia y la incertidumbre sobre algo.

## Introducciones Personales
Aquí hay muchas maneras de introducirnos. Nuestro nombre usando el verbo **chiamarsi**(llamarse) y un par de conjugaciones, además de otros elementos con el fin de hablar de nosotros mismos.

| Italiano      | Español         |
| ------------- | --------------- |
| Io mi chiamo  | Yo me llamo     |
| Io sono       | Yo soy          |
| Il mio nome è | Mi nombre es    |
| Io ho # anni  | Yo tengo # años |

> [!example] 
> Mi chiamo Fabio. → Me llamo Fabio.

| Italiano   | Español     |
| ---------- | ----------- |
| Il cognome | El apellido |
| Il nome    | El nombre   |

> Tengamos en cuenta esta curiosidad en la traducción para no cometer errores.

## Registro

Otro elemento importante es el [[El Registro\|registro]] de formalidad e informalidad para referirnos a otras personas al momento de preguntarles algo. Es importante saber que al usar el pronombre ‘Tu’, usamos una forma de habla informal y ‘Lei’ sería su contra-parte formal

> [!example] 
> - Come ti chiami (tu)? → Cómo te llamas (tú)?
> - Come si chiama Lei? → Cómo se llama usted?

> En las siguientes secciones revisaremos el uso de los pronombres y sus características, por ahora lo más importante es darle uso a estas expresiones.


___

| Italiano           | Español                |
| ------------------ | ---------------------- |
| Da dove vieni?     | ¿De dónde vienes tú?   |
| Da dove viene Lei? | ¿De dónde viene usted? |
| Dove abiti (tu)?   | ¿Dónde vives tú?       |
| Dove abita Lei?    | ¿Dónde vive usted?     |


Podemos usar estas expresiones para hablar específicamente de nuestra ciudad:

>- Io vengo da → Yo vengo de
>- Io abito/vivo a → Yo vivo en

Sin embargo si deseamos hablar de nuestro país de origen, algunas cosas cambiarán por las [[Las Preposiciones\|preposiciones]] .

---

| Italiano                | Español                      |
| ----------------------- | ---------------------------- |
| Che cosa parli?         | ¿Qué hablas tú?              |
| Che cosa parla Lei?     | ¿Qué habla usted?            |
| Quali lingue parli?     | ¿Cuáles idiomas hablas tú?   |
| Quali lingue parla Lei? | ¿Cuáles idiomas habla usted? |


>- Io parlo italiano. → Yo hablo italiano.

Reconozcamos también los términos formales para referirse a personas con un título:

| Italiano | Español |
| -------- | ------- |
| Signor   | Señor   |
| Signora  | Señora  |
