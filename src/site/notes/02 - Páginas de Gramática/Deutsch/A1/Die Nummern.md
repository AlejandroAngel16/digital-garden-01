## Los Números Cardinales

Los dígitos en francés tienen unas reglas ligeramente distintas en comparación al español aunque realmente el orden sea el mismo. 

**Revisemos las unidades hasta el numero 20:**

| #   | Deutsch | #   | Deutsch  |
| --- | ------- | --- | -------- |
| 1   | Eins    | 11  | Elf      |
| 2   | Zwei    | 12  | Zwölf    |
| 3   | Drei    | 13  | Dreizehn |
| 4   | Vier    | 14  | Vierzehn |
| 5   | Fünf    | 15  | Fünfzehn |
| 6   | Sechs   | 16  | Sechzehn |
| 7   | Sieben  | 17  | Siebzehn |
| 8   | Acht    | 18  | Achtzehn |
| 9   | Neun    | 19  | Neunzehn |
| 10  | Zehn    | 20  | Zwanzig  |

___

Ahora para las decenas, hay algunos cambios bastante grandes que probablemente ya hayas notado; las unidades se dicen primero, antes de las decenas, completamente diferente a los idiomas romances. 

Además utilizaremos ‘und’ para juntarlas.

| #   | Deutsch       | ❌ Incorrecto   |
| --- | ------------- | -------------- |
| 21  | Einundzwanzig | Zwanzigundeins |



> [!info] 
> - El patrón seguirá por lo general este orden y no usaremos ningún guión (-) al escribir los números con letras.
> - La decena del 30 (treinta) tiene un ligero cambio en su pronunciación y escritura.

| Decena | Forma escrita |
| ------ | ------------- |
| 30     | Dreißig       |
| 40     | Vierzig       |
| 50     | Fünfzig       |
| 60     | Sechzig       |
| 70     | Siebzig       |
| 80     | Achtzig       |
| 90     | Neunzig       |



> [!example] 
> Wie alt sind sie? → ¿Qué edad tiene usted?
Ich bin sechsundzwanzig Jahre alt. → Tengo 26 años.

Las centenas, miles y millones son más sencillos en el sentido de que siguen el mismo patrón que el resto de idiomas romances (sin voltear).

| #        | Deutsch              |
| -------- | -------------------- |
| 100      | Einhundert (Hundert) |
| 200      | Zweihundert          |
| 300      | Dreihundert          |
| 1000     | Eintausend           |
| 2000     | Zweitausend          |
| 3000     | Dreitausend          |
| 10000    | Zehntausend          |
| 100000   | Einhunderttausend    |
| 1000000  | Eine Million         |
| 2000000  | Zwei Millionen       |
| 10000000 | Zehn Millionen       |

> [!example]  
> ¿Cómo serían los siguientes números en su forma escrita? 
> 1456 → Eintausendvierhundertsechsundfünfzig.
> 18956 → Achtzehntausendneunhundertsechsundfünfzig.

## Símbolos

| Símbolo | Deutsch          | -/- | Símbolo | Français          |
| ------- | ---------------- | --- | ------- | ----------------- |

| -       | Der Binderstrich | -/- | @       | Das at-Zeichen    |
| :       | Geteilt          | -/- | /       | Der Schrägstrich  |
| =       | Gleich/Egal      | -/- | :       | Die beiden Punkte |
| .       | Der Punkt        | -/- | ;       | Das Semikolon     |
| ,       | Das Komma        | -/- |         |                   |
| ‘       | Die Anrede       | -/- |         |                   |
