# Die Konjunktionen I
#Deutsch #A1 
___
Main Index: [[02 - Páginas de Gramática/Deutsch/Nivel A1・DE\|Nivel A1・DE]]
___
Cuando queramos juntar oraciones para añadir información extra o para contrastar dos clausulas, necesitamos usar ciertas palabras para realizar la conexión. Es bastante importante saber como utilizar las comas y negaciones.

Sin embargo, en el alemán existen varias reglas y complicaciones para utilizar las conjunciones de manera adecuada.

Por ahora comprendamos que existen dos tipos de conjunciones mayores, las conjunciones **coordinantes** y las **subordinadas**. Esto es necesario diferenciarlo debido a que dependiendo del tipo de conjunción, el sintaxis/posición de la oración cambiará.

>Antes que nada, recordemos o aprendamos el concepto de las posiciones. → [[Die Positionen\|Die Positionen]]

## Conjunciones Coordinantes.

Estas conjunciones requerirán usar el verbo en la **posición II**. Es extremadamente similar a como funciona el sintaxis del español.

> - Clausula 1 [Pron. + V.Conj] + Conjunción. + (,) + Clausula 2 [Pron. + V.Conj]

| Deutsch | Español        |
| ------- | -------------- |
| Und     | Y              |
| Aber    | Pero           |
| Oder    | O              |
| Denn    | Porque         |
| Dann    | Entonces/Luego |
| Also    | Entonces       |


> [!example]
> 
> - Marie und Paul sind Freunde. → Marie y Paul son amigos.
> - Er ist müde, aber glücklich → Está cansado, pero feliz.
> - Willst du Tee oder Kaffee? → Quieres tú té o café?
> - Ich bleibe, denn es regnet. → Me quedo porque llueve.
> - Es regnet, also nimm einen Regenschirm mit. → Llueve, entonces toma un paraguas.
> - Er hat Hunger, also isst er. → Tiene hambre, entonces come.

## Conjunciones Subordinantes.

Estas conjunciones requerirán usar el verbo en la **posición final** o en la **posición I**. Es extremadamente diferente a como funciona el sintaxis del español e incluso suena extraño, justo como se utilizan [[02 - Páginas de Gramática/Deutsch/A1/Die Modalverben\|Die Modalverben]].

> - Clausula 1 [Pron. + V.Conj] + Conjunción. + (,) + Clausula 2 [Pron. + Comp. + V.Conj.]
> - Clausula 1 [Pron. + V.Conj] + Conjunción. + (,) + Clausula 2 [V.Conj. + Pron. + Comp.]

| Deutsch | Español        | Posición   |
| ------- | -------------- | ---------- |
| Während | Mientras       | I          |
| Weil    | Porque, ya que | Final      |
| Ohne    | Sin            | Final + zu |
| Danach  | Luego          | I          |
| So      | Así            | I          |


> [!example] 
> - Ich bleibe, weil ich müde bin. (lit)→ Me quedo ya que cansado estoy.
> - Währen ich schlafe, träume ich. → Mientras duermo, sueño yo.
> - Ich esse, danach trinke ich. → Yo como, luego bebo yo.
> - Es ist kalt, so trage ich Mantel. → Hace frío, así que llevo yo abrigo.
> - Sie trinkt Kaffee, ohne etwas zu sagen. → Ella bebe café sin decir algo.
>
