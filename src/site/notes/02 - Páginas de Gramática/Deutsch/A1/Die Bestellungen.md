# Die Bestellungen
#Deutsch #A1 
___
Main Index: [[02 - Páginas de Gramática/Deutsch/Nivel A1・DE\|Nivel A1・DE]]
___
Esta sección reúne elementos de todo el nivel para proponer un contexto de encomendar algo o realizar pedidos de manera común o formal utilizando [[02 - Páginas de Gramática/Deutsch/A1/Die Modalverben\|Die Modalverben]] y una conjugación de nivel más avanzado para crear formalidad.

Si deseamos pedir algo en el contexto de una cafetería, tienda, etc… Utilizamos las siguientes expresiones o las escuchamos por parte del empleado en el lugar.

| Deutsch                                     | Español                   |
| ------------------------------------------- | ------------------------- |
| Wie viel kostet das?                        | ¿Cuánto cuesta eso?       |
| Wie hoch sind die Kosten?<br>Was macht das? | ¿Cuál es el costo?        |
| Kann ich bestellen?                         | ¿Puedo ordenar?           |
| Was darf ich Ihnen bringen?                 | ¿Qué le sirvo a usted?    |
| Was darf es sein?                           | ¿Qué sería?               |
| Zum Essen?                                  | ¿Algo para comer/beber?   |
| Sonst noch etwas?                           | ¿Algo más?                |
| Kann ich mit Karte zahlen?                  | ¿Puedo pagar con tarjeta? |
| Es geht nur bar.                            | Solo con efectivo.        |


> [!note] 
> - Estas expresiones serán considerablemente útiles para comprender una conversación centrada en este contexto.
> - Entender exactamente como se forman no es completamente necesario, lo más importante es interpretarlas.

Por otra parte, existen formas de habla que se utilizan para poder expresar el deseo de algo o la necesidad a partir del verbo [[02 - Páginas de Gramática/Deutsch/A1/Die Verben – Sein und Haben\|haben o sein]].

| Deutsch                          | Español        |
| -------------------------------- | -------------- |
| Hunger haben                     | Tener hambre   |
| durstig sein                     | Tener sed      |
| Bock haben auf<br>Lust haben auf | Tener ganas de |
- **Bock/Lust  haben auf** es una expresión bastante común para hablar de algo que se antoje:
    - Ich habe Bock auf Pizza. → Tengo ganas de pizza.
    - Ich habe Lust, zu etwas essen. → Tengo ganas de comer algo.

## Pedidos Formales

En el caso de querer hacer peticiones formales, podemos utilizar ciertos verbos para exigir algo (poder, querer, gustar, tener). Sin embargo, estos verbos deben utilizarse en [[El Condicional\|condicional presente]]; o más bien, el **Konjunktiv II Präteritum** del alemán. ¿Qué significa eso? Que utilizaremos esta conjugación avanzada del alemán para añadir un nivel de formalidad.

Esta conjugación → [[Der Konjunktiv II Präteritum\|Der Konjunktiv II Präteritum]] hace parte de un nivel avanzado, por esta razón solo se aprenderá ligeramente en lo que resta de la sección actual.

En la siguiente tabla se recopilarán estos verbos en [[Der Konjunktiv II Präteritum\|Der Konjunktiv II Präteritum]] junto a ejemplos de su uso:

| Subjektpronomen | Mögen    | Können   | Haben   |
| --------------- | -------- | -------- | ------- |
| Ich             | möchte   | könnte   | hätte   |
| Du              | möchtest | könntest | hättest |
| Es              | möchte   | könnte   | hätte   |
| Wir             | möchten  | könnten  | hätten  |
| Ihr             | möchtet  | könntet  | hättet  |
| Sie             | möchten  | könnten  | hätten  |

> [!example] 
> - ich möchte einen Kaffee, bitte. → Me gustaría un café, por favor.
> - Er hätte gern einen Te. → Él tendría un te con gusto.
> - Wir möchten in ein Café gehen. → Nos gustaría/quisieramos ir a un café.
> - Könnten Sie bitte eine Käseplatte bringen?→ Podrían traer una bandeja de quesos?
> - Könnten Sie mir helfen? → Podría ayudarme?
