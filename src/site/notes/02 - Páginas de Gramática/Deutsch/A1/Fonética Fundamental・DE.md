# Fonética Fundamental
#Deutsch  #A1 
___

El alemán tiene un sistema fonético claro y bastante directo, con reglas claras que pueden facilitar el aprendizaje de estas mismas. Para poder aprovechar al máximo el estudio fonético del alemán, debemos conocer bien como funciona el IPA y hacer constante práctica de estos sonidos, ya que entre el español y el francés existen considerables diferencias.

## Vocales Únicas

> Aprendamos que la ‘h’ después de una vocal, en alemán, hace que el sonido se alargue un poco más. Sin embargo, la ‘h’ al inicio de una palabra sonará expirada, similar a una ‘j’ del español.

| Vocal | Representación por IPA |
| ----- | ---------------------- |
| a     | /a/                    |
| i     | /ɪ/                    |
| u     | /ʊ/                    |
| e     | /ɛ/                    |
| o     | /ɔ/,/o/                |
| ä     | /ɛː/                   |
| ö     | /øː/                   |
| ü     | /yː/                   |

> [!TIP] Ejemplos
> - Tür → /tyːɐ̯/
> - Kind → /kɪnt/
> - Schön → /ʃøːn/
## Combinaciones Vocales

| Comb. Vocal | Representación por IPA |
| ----------- | ---------------------- |
| ei          | /ai/                   |
| au          | /aʊ/                   |
| eu          | /ɔɪ̯/                  |
| äu          | /ɔɪ̯/                  |
| ie          | /i:/                   |


> [!TIP] Ejemplos
> - Mein → /maɪn/
> - Haus → /haʊs/
> - Neu → /nɔɪ̯/
> - Einkäufe → /aɪ̯nkɔɪ̯fə/

## Combinación de Consonante

| Comb. Cons. | Representación por IPA |
| ----------- | ---------------------- |
| Sch         | /ʃ/                    |
| Pf          | /pf/                   |
| Z           | /ts/                   |
| R           | /ʁ/                    |
| Ch          | /ç/, /x/               |
| W           | /v/                    |
| V, F        | /f/                    |

> [!TIP] Ejemplos
> - Schule → /ˈʃuːlə /
> - Ich → /ɪç/
> - Zeit → /t͡saɪt/
