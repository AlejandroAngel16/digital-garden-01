# Die Bestimmte und unbestimmte Artikel・Nominativ
#Deutsch #A1
___
Main Index: [[02 - Páginas de Gramática/Deutsch/Nivel A1・DE\|Nivel A1・DE]]
___

> ⭐ Esta sección se hace teniendo en cuenta el [[02 - Páginas de Gramática/Deutsch/Extras/Der Nominativ\|caso nominativo]] y es una pequeña introducción a este. Sin embargo, sí es recomendable revisar esta sección primero si esta resulta confusa.

## Artículos Definidos

La lengua alemana, diferente pero simular al español como el español, tiene géneros. Sin embargo, y esta es una cualidad compleja del idioma, deberemos de lidiar con 3 géneros → **masculino, femenino y neutro** para cada sustantivo. 

Hay muy ligeras reglas para poder identificar el género de una palabra. Aún así, existe una gran cantidad de excepciones y por esta razón, tiene más sentido aprender el genero de cada palabra directamente por memoria o por ciertos patrones

>Podemos ver los patrones definidos por genero en el siguiente artículo:
>- https://en.wikipedia.org/wiki/Grammatical_gender_in_German (aunque puede ser confuso tomar esta información en cuenta al inicio.)

Este artículo (definido) nos permite hablar de un elemento **específico** que se usara como el sujeto de la oración. (Sobretodo porque estos artículos representan al [[02 - Páginas de Gramática/Deutsch/Extras/Der Nominativ\|caso nominativo]]) 

| Género                  | Art. Definido - Deutsch | Traducción - Español           |
| ----------------------- | ----------------------- | ------------------------------ |
| Masculino Singular      | Der                     | El                             |
| Femenino Singular       | Die                     | La                             |
| Neutro Singular         | Das                     | El/La (sin traducción directa) |
| Masc./Fem./Neut. Plural | Die                     | Los/Las                        |


> [!info] 
> - El artículo **Die** sirve tanto para sustantivos femeninos singulares como para cualquier sustantivo plural, esto podría ser confuso al inicio pero dependiendo del contexto, se vuelve más sencillo identificar las diferencias.

> [!example] 
> - Die Schränke sind heute schön. → Los armarios están bonitos hoy.
> - Die Blume blüht jeden Tag. → La flor florece cada día.

## Artículos Indefinidos

Este artículo nos permite hablar de un elemento **no específico** que también se comporte como el sujeto de una oración. Este artículo es una contra parte del artículo definido aunque se comporte ligeramente distinto.

| Género             | Art. Indefinido - Deutsch | Traducción - Español            |
| ------------------ | ------------------------- | ------------------------------- |
| Masculino Singular | Ein                       | Un                              |
| Femenino Singular  | Eine                      | Una                             |
| Neutro Singular    | Ein                       | Un/Una (Sin traducción directa) |



> [!info] 
> - No existe un [[Los Artículos\|artículo indefinido]] plural para ningún género en el idioma alemán. O sea que ‘unos/unas’ será reemplazado por otras alternativas.
> - **Einige** o **Ein paar** son alternativas para nombrar cosas plurales de manera indefinida, aunque la traducción de estas palabras es más cercana a **varios** o **algunos**.


> [!example] 
> - Eine Orange duftet gut. → Una naranja huele bien.
> - Ein Problem kann gelöst werden. → Un problema puede ser solucionado.
