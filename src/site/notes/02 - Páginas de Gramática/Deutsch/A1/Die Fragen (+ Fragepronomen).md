# Die Fragen (+ Fragepronomen)
#Deutsch #A1

## Preguntas Negativas & Positivas (Ja/Nein)

Realizar preguntas en alemán requiere entender el registro de formalidad ya que de acuerdo a este, la formación de cada pregunta variará. Iniciemos por las preguntas cuya respuesta siempre es directamente positiva o negativa. Se les escucha mucho como preguntas sí/no.

### Preguntas Estándar

**La Inversión** → Este es un concepto normalmente usado para introducir preguntas cuando se trata de idiomas germánicos como lo es el alemán. Se considera una forma estándar de habla, o sea que, independientemente de si la pregunta es formal o informal (du/Sie), la estructura es la misma.

**La Inversión** es el proceso en el cual simplemente cambiamos de posición el sujeto y el verbo en conjugación simple, de esta manera lo siguiente pasará:

>- Ich liebe → Liebe ich

Al realizar este paso, la oración toma un tono interrogativo.


> [!NOTE] 
> - V.Conj. +  Pron.(Suj) + (nicht) + Comp ?


> [!example] 
> - Arbeiten Sie? → ¿Usted trabaja?
> - Wohnt er hier? → ¿Él vive aquí?
> - Essen sie nicht? → ¿Ellas no comen?
> - Kommst du mit, oder nicht? → Vienes conmigo o no?

## Pronombres Interrogativos
Cuando queremos respuestas directas y detalladas sobre el modo, localización o la razón por la cual algo se realizó, utilizamos ciertos pronombres. → [[Los Pronombres Interrogativos\|Los Pronombres Interrogativos]]

| Pronomen  | Español            | -/- | Pronomen   | Español  |
| --------- | ------------------ | --- | ---------- | -------- |
| Was       | Qué                | -/- | Wen        | A quién  |
| Wann      | Cuándo             | -/- | Welche/r/s | cuál     |
| Wer       | Quién              | -/- | Woher      | De dónde |
| Warum     | Por qué            | -/- | Wohin      | A dónde  |
| Wie       | Cómo               | -/- |            |          |
| Wo        | Dónde              | -/- |            |          |
| Wie viele | Cuánto/a/os/as     | -/- |            |          |
| Wie lange | Qué tanto (tiempo) |     |            |          |


> Sí, como se ve en la tabla, existen [[Los Pronombres Interrogativos\|pronombres interrogativos]] que ya están fusionados junto a una preposición de lugar/proveniencia, este es un detalle importante para saber qué [[02 - Páginas de Gramática/Deutsch/Extras/Die grammatikalischen Kasus\|caso gramatical]] usar.



> [!info] 
> - Los pronombres interrogativos también se pueden utilizar para hacer oraciones con Cláusulas Relativas.
> - El pronombre **Welche** se usa formas distintas dependiendo del género y el caso, aunque es un poco complicado al inicio, podemos decir que sigue los patrones del artículo definido. (-er, -e, -es, -e.)
> - En el caso de utilizar **warum**, es necesario justificar con la conjunción **denn** u otra conjunción para justificar. (aunque otra formas de justificación existen).

> Se puede revisar el uso adecuado de **welche** en la página general de → [[02 - Páginas de Gramática/Deutsch/Extras/Die grammatikalischen Kasus\|Die grammatikalischen Kasus]]

### Preguntas Estándar 

Al igual que las preguntas “Ja/Nein”, al realizar preguntas en alemán usando los [[Los Pronombres Interrogativos\|pronombres interrogativos]], solo debemos hacer una **inversión**.

> [!NOTE] 
> - Pron.(Interrog) + V.Conj. + Pron.(Suj) + (nicht) + Comp ?

> [!example] 
> - Was bist du von Beruf? → ¿A qué te dedicas en la vida?/¿Qué eres por profesión?
> - Warum ist er hier? → ¿Por qué está él acá?
> 	- Denn er ist frei. → Porque él es libre.
> - Woher kommen Sie? → ¿De dónde viene usted?
> - Wie lange sind sie schon in Deutschland? → ¿Desde hace cuanto tiempo están ellos en Alemania?
> - Welches Buch liest du? → ¿Cuál libro lees? 
>
