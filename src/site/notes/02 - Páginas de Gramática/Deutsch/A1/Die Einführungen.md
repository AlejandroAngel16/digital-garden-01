## Saludos Introductorios

Cuando nos introducimos ante una persona nueva, lo primero que tenemos en cuenta es el tiempo del día. ¿Es de mañana, tarde, noche? Es importante conocer que la forma en como se interpreta el tiempo dentro del lenguaje alemán, es muy seguramente distinta si tú no vives en el país objetivo.

| Deutsch      | Español       |
| ------------ | ------------- |
| Guten Morgen | Buenos días   |
| Guten Tag    | Buenas tardes |
| Guten Abend  | Buenas tardes |
| Gute Nacht   | Buenas noches |


> [!info]
> - **Guten Morgen** es un saludo matinal que va desde las 6 a.m. hasta las 12 p.m.
> - **Guten Tag** es usado entre las 12 p.m. hasta las 5 o 6 p.m.
> - **Guten Abend** es usado entre las 5-6 p.m. hasta la medianoche.
> - **Gute Nacht** es un saludo específico para despedirse en la noche antes de dormir o para la madrugada antes de que salga el sol.

Podemos decir entonces que el uso de estas [[La Perífrasis Verbal y Locución Verbal\|locuciones verbales]] tienen seguramente un uso cultural distinto, por eso es bastante importante conocer el contexto en el cual se usan estas palabras.
## Saludos Breves

Si deseamos ser más directos o familiares con nuestros saludos, hay muchas formas dependiendo del nivel de familiaridad que tengamos con la otra persona.

| Deutsch            | Español                 |
| ------------------ | ----------------------- |
| Hallo/Ciao         | Hola/adiós              |
| Alles klar?        | ¿Cómo estás? ¿Cómo vas? |
| Willkommen         | Bienvenido(a)           |
| Freut mich         | Encantado(a)            |
| -/-                | -/-                     |
| Wie geht es ihnen? | ¿Cómo le va? (formal)   |
| Wie geht’s dir?    | ¿Cómo te va? (casual)   |

> [!info] 
> - **Wie geht es ihnen?** es una pequeña locución que utiliza el [[02 - Páginas de Gramática/Deutsch/Extras/Der Dativ\|caso dativo]] para preguntar por la vida de alguien y su estado actual.

## Despedidas

Hay bastantes formas de despedirse (sich verabschieden) también, unas más usadas que otras y unas más formales que otras.

| Deutsch            | Español                   |
| ------------------ | ------------------------- |
| Tschüss            | Adiós (casual)            |
| Bis später         | Hasta luego               |
| Bis bald           | Hasta pronto / Nos  vemos |
| Hallo              | Hola                      |
| Auf Wiedersehen    | Adiós                     |
| Schönen Tag        | Ten un buen día           |
| Schönes Wochenende | Ten un buen fin de semana |


> Otras formas de saludar existen en alemán debido a su riqueza cultural en relación a dialectos, acentos y formas de habla. Según la región podemos decir → **Servus, moin moin, hoi**!

> [!info] 
> - **Ciao**, aunque comúnmente conocido como un saludo italiano, también es común para saludar y despedirse en el alemán.
> - Hay que comprender que el uso de estos saludos varía según el [[El Registro\|registro]], el contexto de la oración y la región.

## Afirmaciones y Negaciones

No nos podemos olvidar de palabras tan importantes para hacernos expresar como ‘sí’ y ‘no’.

| Deutsch         | Español      |
| --------------- | ------------ |
| Ja              | Sí           |
| Nein            | No           |
| Nee/Nö          | No           |
| Natürlich       | Claro        |
| Natürlich nicht | Claro que no |

> [!info] 
> **Nö** o **Nee** son solo otra forma de decir “nein”, bastante familiar y no usada en contextos formales.

## Disculpas y Expresiones Menores

| Deutsch                 | Español                                |
| ----------------------- | -------------------------------------- |
| Es tut mir leid         | Lo siento                              |
| Entschuldigung          | Disculpa                               |
| Entschuldigen Sie bitte | Discúlpeme, por favor.                 |
| Wie bitte?              | Perdón?                                |
| -/-                     | -/-                                    |
| So lala                 | Ni fu ni fa/Así o asá/Pues sí, pero no |
| Mehr oder weniger       | Más o menos                            |

> [!info] 
> **Entschuldigung** es una expresión común y se asocia comúnmente a la expresión ‘disculpe’. Es bastante común usarla en diferentes contextos y fonética-mente tiene un ligero cambio tonal que la hace sonar melódica y amigable.

## Introducciones Personales

Aquí hay muchas maneras de introducirnos. Nuestro nombre usando el verbo **heißen** (llamarse) y un par de conjugaciones, además de otros elementos con el fin de hablar de nosotros mismos.

| Deutsch             | Español         |
| ------------------- | --------------- |
| Ich heiße           | Yo me llamo     |
| Ich bin             | Yo soy          |
| Mein Name ist       | Mi nombre es    |
| Ich bin # Jahre alt | Yo tengo # años |

> Debido a que el alemán es una lengua germánica como el [[01 - Índices/Páginas de Idiomas/English\|inglés]], la edad se expresa usando el verbo  ‘ser’ mas no usando ‘tener’. O sea que en este tipo de idiomas, uno mismo es la edad.


> [!example] 
> Ich heiße Fabio. → Me llamo Fabio.

| Deutsch          | Español                   |
| ---------------- | ------------------------- |
| Der Familienname | El apellido               |
| Der Vorname<br>  | El nombre (primer nombre) |
| Der Name         | El nombre                 |

## Registro

Otro elemento importante es el [[El Registro\|registro]] de formalidad e informalidad para referirnos a otras personas al momento de preguntarles algo. Es importante saber que al usar el pronombre **Du**, usamos una forma de habla informal y **Sie** sería su contra-parte formal

> [!example] 
> - Wie heißt du? → Cómo te llamas tú?
> - Wie heißen sie? → Cómo se llama usted?

> En las siguientes secciones revisaremos el uso de los pronombres y sus características, por ahora lo más importante es darle uso a estas expresiones.


___

| Deutsch           | Español                |
| ----------------- | ---------------------- |
| Woher kommst du?  | ¿De dónde vienes tú?   |
| Woher kommen Sie? | ¿De dónde viene usted? |
| Wo wohnst du?     | ¿Dónde vives tú?       |
| Wo wohnen Sie?    | ¿Dónde vive usted?     |


Podemos usar estas expresiones para hablar específicamente de nuestra ciudad:

>- Ich komme aus… → Yo vengo de…
>- Ich wohne in… → Yo vivo en…

Sin embargo si deseamos hablar de nuestro país de origen, algunas cosas cambiarán por las [[Las Preposiciones\|preposiciones]] .

---

| Deutsch                       | Español                      |
| ----------------------------- | ---------------------------- |
| Was sprichst du?              | ¿Qué hablas tú?              |
| Was sprechen Sie?             | ¿Qué habla usted?            |
| Welche Sprachen sprichst du?  | ¿Cuáles idiomas hablas tú?   |
| Welche Sprachen sprechen Sie? | ¿Cuáles idiomas habla usted? |

>- Ich spräche Deutsch. → Yo hablo alemán.

Reconozcamos también los términos formales para referirse a personas con un título:

| Deutsch    | Español |
| ---------- | ------- |
| Herr (Hr.) | Señor   |
| Frau (Fr.) | Señora  |
