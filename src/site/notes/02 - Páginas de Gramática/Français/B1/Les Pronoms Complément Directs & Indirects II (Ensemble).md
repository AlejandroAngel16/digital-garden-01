# Les Pronoms Complément Directs & Indirects II (Ensemble)
#Français #B1
___
Main Index: [[02 - Páginas de Gramática/Français/NIVELES/Nivel B1・FR\|Nivel B1・FR]]
___
Previa a esta sección → [[02 - Páginas de Gramática/Français/A2/Les Pronoms Complément I (COD-COI)\|02 - Páginas de Gramática/Français/A2/Les Pronoms Complément I (COD-COI)]], donde se explica detalladamente las diferencias entre un tipo de pronombre y el otro, además de su uso **por separado**.

Recordemos la ‘Estructura de Una Oración:
[image]

- El COD de una oración responde a la pregunta → ¿Qué/Quién? ¿Qué está siendo afectado?
- Y el COI de una oración responde a → ¿A qué/A quién? ¿A qué se dirige la acción?

Si llegamos a utilizar el pronombre de ambos elementos **a la vez**, estaremos sujetos a ciertas condiciones.
Recordemos los [[02 - Páginas de Gramática/Français/A2/Les Pronoms Complément I (COD-COI)\|Pronombre Complemento Directo y Complemento Indirecto]]:

| Pronombre Sujeto | Pronombre COD | Pronombre COI |
| ---------------- | ------------- | ------------- |
| Je               | Me/m’         | Me/m’         |
| Tu               | Te/t’         | Te/t’         |
| Il/elle          | Le/la/l’      | Lui           |
| Nous             | Nous          | Nous          |
| Vous             | Vous          | Vous          |
| Ils/elles        | Les           | Leur          |

Hay que recordar que dentro de esta categoría también se encuentran los pronombres _**y** & **en**_ que se comportan de manera similar a un pronombre [[El Complemento Directo\|complemento directo]] pero también tienen reglas específicas para juntarse con los pronombre de la tabla.

> Un detalle bastante confuso es que dependiendo del Pronombre Complemento Indirecto, la posición de este y el Pronombre Complemento Directo cambiarán lugares.

## Estructura sencilla (1 verbo)

Utilizando el Pron(COI) → **Me, Te, Nous, Vous**

> [!NOTE] 
>La posición de los pronombres en estructuras simples es similar a aquella del español.
>
 >- Suj. + (ne) + Pron.(COI) + Pron.(COD) + V.Conj. + (pas) + Comp.

> [!example] 
> - Tu peux me passer la lettre?
> 	- Non, Je **ne te** la passe pas.
> 
> 
> - Est-ce qu’il vous décrit la situation.
> 	- Pas du tout, il ne **nous la** décrit pas.

Utilizando el Pron(COI) → **Solo para: Lui, Leur**

> [!NOTE]
> La posición para estos pronombres va a cambiar su syntax y desde un punto de vista hispano, está completamente al revés.
> 
> - Suj. + (ne) + Pron.(COD) + Pron.(COI) + V.Conj. + (pas) + Comp.

> [!example]
> 
> - Tu peux passer la tasse a mon frère?
> 	- je ne **la lui** passe pas. → Yo no se la paso. (a él)
> - Et vous allez enseigner la présentation aux gens du public.
> 	- Oui, on **la leur** enseigne et c’est fini. → Sí, se la enseñamos y se acabó.

Utilizando el Pron(COI) **+ Y / En**

> [!NOTE]
> No necesariamente usaremos los pronombres COD y COI juntos con Y/EN ya que no se escucha muy natural usar absolutamente todo junto. Por esto la distinción con → “/”
> 
> - Suj. + (ne) + Pron.(COD) / Pron.(COI) + Pron. (Y) / Pron. (En) + V.Conj. + (pas) + Comp.

> [!example]
> 
> - Ils devraient laisser les clés sur la table.
> 	- Ouais, ils **les y** laisseront. 
> - Tu nous parles de tes problèmes?
> 	- Oui, je **vous en** parle toujours!

## Estructura Estructura Modal (2 verbos)

Utilizando el Pron(COI) → **Me, Te, Nous, Vous**

> [!NOTE]
> 
> - Suj. + (ne) + V.Conj. + (pas) + Pron.(COI) + Pron.(COD) + V.Infi. + Comp.

> [!example]
> 
> - Mais, allez, dis-moi l’information.
> 	- Je ne vais pas **te la** dire.

Utilizando el Pron(COI) → **Solo para: Lui, Leur**

> [!NOTE]
> 
> - Suj. + (ne) + V.Conj. + (pas) + Pron.(COD) + Pron.(COI) + V.Infi. + Comp.

> [!example]
> - Tu penses qu’il mérite savoir sur la lettre?
> - je ne vais pas **la lui** offrir. → No se la voy a ofrecer. (a él)

Utilizando el Pron(COI)**+ Y / En**

> [!NOTE]
> 
> - Suj. + (ne) + V.Conj + (pas) Pron.(COD) / Pron.(COI) + Pron. (Y) / Pron. (En) + V.Infi. + Comp.

> [!example]
> 
> - Et elle? Que pense-t-elle de sa situation?
> 	- Elle peut **leur en** parler, mais…
> - On devrait aller au ciné, non?
> 	- Tu dois **nous y** conduire.

## Estructura Compuesta (+ participio)
> Debido a que estamos utilizando una conjugación compuesta junto a un pronombre complemento directo, el verbo en [[El Participio Pasado\|participio pasado]] debe de estar concordado.

Utilizando el Pron(COI) → **Me, Te, Nous, Vous**

> [!NOTE]
> 
> - Suj.+ (ne) + Pron.(COI) + Pron.(COD) + V.Aux. + (pas) + V.Participe(Concordado) + Comp.

> [!example]
> 
> - Je ne **vous l'ai** pas passée. → No se la he pasado. (a ustedes)

Utilizando el Pron(COI) → **Solo para: Lui, Leur**

> [!NOTE]
> 
> - Suj.+ (ne) + Pron.(COD) + Pron.(COI) + V.Aux. + (pas) + V.Participe(Concordado) + Comp.

> [!example]
> 
> - Je ne **la lui** ai pas passée. → No se la he pasado. (a él)

Utilizando el Pron(COI) **+ Y / En**

> [!NOTE]
> 
> - Suj. + (ne) + Pron.(COD) / Pron.(COI) + Pron. (Y) / Pron. (En)  + V.Aux. + (pas) + V.Participe(Concordado) + Comp.

> [!example]
> 
> - Vous avez rangé les papiers?
> 	- On **les y** a rangés.
> - Vous avez fait la présentation de la ville à votre professeur?
> 	- On **lui en** a tout présenté.
